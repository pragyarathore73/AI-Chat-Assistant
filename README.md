## 📝 About the Project

**AI Chat Assistant** is an AI-powered conversational web application built using **React.js** and the **Google Gemini API**.

The application allows users to enter their queries and receive AI-generated responses through a simple and interactive chat interface.

This project demonstrates practical implementation of **React.js, Context API, API integration, state management, and asynchronous operations**.

---

## ✨ Key Features

- 🤖 **AI-Powered Responses:** Generates responses using the Google Gemini API.

- 💬 **Interactive Chat:** Users can send queries and receive AI-generated responses.

- ⌨️ **Easy Query Submission:** Queries can be submitted using the **Enter key or Send button**.

- 🕘 **Recent Prompts:** Displays recently submitted queries.

- 📝 **Markdown Support:** Renders AI responses with proper Markdown formatting.

---

## 💻 Technologies & Tools

**Frontend:** React.js, JavaScript, HTML5, CSS3

**AI Integration:** Google Gemini API

**State Management:** React Context API

**Response Rendering:** React Markdown

**Development Tools:** Vite, Git, GitHub, VS Code
